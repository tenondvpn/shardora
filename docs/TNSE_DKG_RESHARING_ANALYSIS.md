> 1. 13.T4 新成员份额初始化协议是否安全？
> 2. 通信复杂度声明是否准确？
> 3. 从严格数学推导出发，最优更替率 ρ* 是多少？

## 二、问题一：朴素 Lagrange 方案的安全漏洞

### 2.1 漏洞成因

原 13.T4 方案：旧成员 $i$ 将自身原始份额 $sk_i^{(t)}=F^{(t)}(i)$ 经 ECDH 加密发给新成员 $j$，$j$ 收集 $t$ 个后 Lagrange 插值。

新成员 $j$ 合法接收 $\{(i_l,\; sk_{i_l}^{(t)})\}_{l=1}^{t}$，即 $F^{(t)}(x)$ 在 $t$ 个**不同**位置上的值。由于 $F^{(t)}$ 是 $t-1$ 次多项式（$t-1=341$ 次，需 $t=342$ 个点唯一确定），$j$ 可插值出完整多项式并计算：

$$F^{(t)}(0) = \sum_{l=1}^{t}\lambda_l^{(0)}\cdot sk_{i_l}^{(t)} = sk_{\rm common}$$

### 2.2 ECDH 为何不能修复此漏洞

ECDH 保护的是**信道机密性**（传输过程不可被第三方截获），而不改变**信息量**（$j$ 解密后持有的内容）。

类比：信封只保证邮路机密，收件人拆封后读到的信息量不受信封影响。$j$ 解密后仍持有 $t$ 个原始份额，仍可插值。

| | 保护目标 | 能否防止 $j$ 插值 $sk_{\rm common}$ |
|--|---------|----------------------------------|
| ECDH | 信道机密性（防第三方窃听） | **否** |
| 可验证重分享 | 接收方的信息量上界 | **是** |

## 三、正确方案：可验证重分享子协议

### 3.1 核心原则

旧成员 $i$ 不发送 $sk_i^{(t)}=F^{(t)}(i)$（**自身位置**的值），
而是生成新随机多项式 $q_i(x)$ 满足 $q_i(0)=sk_i^{(t)}$，
发送 $q_i(j+1)$（**接收者位置**的值）。

$j$ 只能获得各 $q_i$ 在同一点 $j+1$ 的值；从单点无法还原任一 $q_i(0)$。

### 3.2 协议步骤

**步骤 1（旧成员构造贡献多项式）**

每个旧成员 $i\in S$（$|S|=t_{\rm DKG}+1=684$），均匀随机选取 $b_{i,1},\ldots,b_{i,t_{\rm DKG}-1}\in\mathbb{Z}_p$，令：

$$q_i(x) = sk_i^{(t)} + b_{i,1}x + \cdots + b_{i,t_{\rm DKG}-1}x^{t_{\rm DKG}-1}$$

满足 $q_i(0)=sk_i^{(t)}$，随机系数对外不可见。

**步骤 2（ECDH 加密单播至新成员 $j$）**

$$K_{ij} = \mathrm{ECDH}(sk_i^{\rm EC},\; pk_j^{\rm EC}), \quad \text{发送 } \mathrm{Enc}(K_{ij},\; q_i(j+1))$$

**步骤 3（新成员聚合）**

$$sk_j^{(t)} = \sum_{i\in S}\lambda_i^{S,0}\cdot q_i(j+1), \quad \lambda_i^{S,0}=\prod_{l\in S,l\neq i}\frac{-l}{i-l}$$

### 3.3 正确性证明

令 $R(x)=\sum_{i\in S}\lambda_i^{S,0}\cdot q_i(x)$（$t_{\rm DKG}-1$ 次多项式），则：

$$R(0)=\sum_{i\in S}\lambda_i^{S,0}\cdot q_i(0)=\sum_{i\in S}\lambda_i^{S,0}\cdot sk_i^{(t)}=\sum_{i\in S}\lambda_i^{S,0}\cdot F^{(t)}(i)=F^{(t)}(0)=sk_{\rm common}$$

因此 $R$ 是 $F^{(t)}$ 的合法重分享多项式，$sk_j^{(t)}=R(j+1)=F^{(t)}(j+1)$。$\square$

### 3.4 安全性证明（信息论）

对固定 $i\in S$，$j$ 观测到方程：

$$q_i(j+1) = sk_i^{(t)} + \sum_{l=1}^{t_{\rm DKG}-1} b_{i,l}(j+1)^l$$

共 $t_{\rm DKG}-1=682$ 个自由系数 $\{b_{i,l}\}$，均对 $j$ 不可见。给定 $q_i(j+1)$，$sk_i^{(t)}=q_i(0)$ 的条件熵：

$$H\!\left(sk_i^{(t)}\;\middle|\;q_i(j+1)\right) = H\!\left(sk_i^{(t)}\right) = \log_2 p$$

即零信息增益。对所有 $i\in S$ 独立成立，故 $j$ 无法恢复 $sk_{\rm common}=F^{(t)}(0)$。$\square$

## 四、问题二：通信复杂度的正确分析

### 4.1 单轮通信组成（任意 $\rho$）

| 阶段 | 公式 | $\rho=10\%$（$k_{\rm new}=102$） | $\rho^*=25\%$（$k_{\rm new}=256$） |
|------|------|:---:|:---:|
| (A) 份额引导 | $(t_{\rm DKG}+1)\times k_{\rm new}$ | 684×102 = **69,768** | 684×256 = **175,104** |
| (B1) 留任差量 | $k_{\rm ret}\times k_{\rm new}$ | 922×102 = **94,044** | 768×256 = **196,608** |
| (B2) 新成员广播 | $k_{\rm new}\times(k-1)$ | 102×1022 = **104,244** | 256×1022 = **261,632** |
| **合计** | | **268,000** | **633,000** |

全量标准 DKG：$k(k-1)=1{,}047{,}552$ 条。

### 4.2 两个维度的节省

**维度 A：报文条数节省**

$$\text{节省}_{10\%} = 1 - \frac{268{,}000}{1{,}047{,}552} \approx 74.4\%$$

$$\text{节省}_{25\%} = 1 - \frac{633{,}000}{1{,}047{,}552} \approx 39.6\%$$

**维度 B：差量多项式承诺体积节省（TNSE 核心贡献）**

TNSE 中每节点只广播差量多项式 $h_i^{(t)}(x)$ 的承诺，阶数为 $\lfloor\rho\cdot t_{\rm DKG}\rfloor$；相比全量承诺（683 阶）：

$$\text{承诺节省}_{10\%} = 1 - \frac{68}{683} \approx 90\%$$

$$\text{承诺节省}_{25\%} = 1 - \frac{170}{683} \approx 75\%$$

> **注**：文档及论文中"81%""73%"等数字指的是**承诺体积**维度，不是报文条数。两个维度都有改善，但量级不同。

### 4.3 渐近复杂度

$$C_{\rm total}(\rho) = O(k \cdot k_{\rm new}) = O(k^2 \cdot \rho)$$

渐近复杂度随 $\rho$ 线性缩放。从性能角度 $\rho$ 越小越好，但密码学安全性要求 $\rho\geq22.85\%$（下节证明）。两个目标存在 Pareto 张力，最优平衡点在 $\rho^*=25\%$。

## 五、问题三：Pareto 最优更替率 ρ* = 25%

### 5.1 优化问题形式化

$$\min_{\rho\in(0,1]}\; C_{\rm comm}(\rho) \quad \text{s.t.} \quad \begin{cases} \mathbf{C_1:} & (1-\rho)^{342} \leq 2^{-128} \\ \mathbf{C_2:} & 1/\rho \leq \tau_{\max} \\ \mathbf{C_3:} & B_{\rm peak}(\rho) \leq B_{\rm WAN} \end{cases}$$

### 5.2 约束 C1：128-bit 移动对手安全下界（精确解 ρ ≥ 22.85%）

移动对手跨轮持续腐化节点 $i$，节点停时 $\tau_i$ 达到插值门限 $t=342$ 的概率（定理 13.15' 导出）：

$$P_{\rm leak}(\rho) = \Pr[\tau_i \geq 342] \leq (1-\rho)^{342}$$

要求 $P_{\rm leak}\leq 2^{-128}$：

$$(1-\rho)^{342} \leq 2^{-128}$$

$$342\cdot\ln(1-\rho) \leq -128\ln 2 = -88.7228\ldots$$

$$\ln(1-\rho) \leq -\frac{88.7228}{342} = -0.25942\ldots$$

$$1-\rho \leq e^{-0.25942} = 0.77149\ldots$$

$$\boxed{\rho \geq 1 - e^{-128\ln 2/342} = 22.8504\ldots\%}$$

**当前工程参数 $\rho=10\%$ 的理论缺陷**：

$$(0.9)^{342} \approx 2^{-52.0}$$

仅有约 **52-bit** 安全性，显著低于 128-bit 密码学标准。在无外部退火假设的情况下，单凭 $\rho=10\%$ 的几何衰减不足以对抗移动对手。

### 5.3 约束 C2：自适应物理渗透窗口（要求 ρ ≥ 25%）

节点委员期望持续时间 $\mathbb{E}[\tau]=1/\rho$（几何分布）。

| $\rho$ | $\mathbb{E}[\tau]$ | 物理攻击窗口 |
|--------|-------------------|------------|
| 10% | 10 轮 = 6000 s | **100 分钟** |
| 25% | 4 轮 = 2400 s | **40 分钟** |
| 33% | 3 轮 = 1800 s | 30 分钟 |

物理对手渗透一台委员节点后，享有合法投票权的时间窗口从 100 分钟压缩至 40 分钟（降低 60%），显著增加跨 Epoch 维持 Quorum 立足点的成本。

### 5.4 约束 C3：带宽验证（ρ* = 25% 完全满足）

单节点广播报文大小：

$$\text{msg}(\rho) = \underbrace{(k-1)\times64\text{ B}}_{\approx65.5\text{ KB}} + \underbrace{\lfloor\rho\cdot t_{\rm DKG}\rfloor\times96\text{ B}}_{\text{差量承诺}}$$

取 $\rho^*=0.25$：$\text{msg}=65.5+170\times96/1024\approx80.0$ KB。

全委员会总数据量 $\approx80.0\text{ MB}$，$T_{\rm bls}=190$s 窗口内平均带宽：

$$B_{\rm avg} = \frac{80.0\text{ MB}}{190\text{ s}} \approx 3.53\text{ Mbps} \ll 100\text{ Mbps} = B_{\rm WAN}$$

峰值（单 $T_\varphi=19$s 内）约 35 Mbps，100 Mbps 云主机带宽占用率 $<35\%$，完全满足 C3。

### 5.5 定理 13.15-OPT（Pareto 最优更替率）

**定理**：在 $k=1024$，$t=342$，$N=10^5$，$T=600$s 的 PPKG 协议中，令

$$\rho^* = 25\% = \frac{2^8}{2^{10}} \quad (k_{\rm new}=256,\; k_{\rm ret}=768)$$

则系统同时满足以下四条性质：

**(P1) 128-bit 移动抗性（无退火依赖）**

$$\Pr[\tau_i \geq 342] \leq (1-\rho^*)^{342} = (0.75)^{342} \approx 2^{-141.9} \ll 2^{-128}$$

无需外部 FTS 退火假设，仅凭 $\rho^*=25\%$ 的几何衰减即原生超越 128-bit 安全红线。

**(P2) 稳态全局采样率精确自洽**

由于 $k_{\rm new}=k\cdot\rho^*=1024\times0.25=256$（精确整除），稳态参与率：

$$\bar{p}_i = \frac{1/\rho^*}{1/\rho^* + (N-k)/k_{\rm new}} = \frac{4}{4+98976/256} = \frac{4}{4+386.625} = \frac{1024}{100000} = \alpha_{\rm global}$$

精确闭合。（$\rho=10\%$ 时 $k_{\rm new}=102\neq102.4$，舍入导致微小不自洽。）

**(P3) DKG 通信在广域网范围内（75% 承诺体积节省）**

差量承诺阶数 $170$，承诺体积节省 $1-170/683\approx75\%$；单节点报文 80.0 KB，190s 窗口带宽仅 3.53 Mbps（$\ll100$ Mbps），满足约束 C3。

**(P4) 自适应攻击窗口压缩 60%**

$\mathbb{E}[\tau]=4$ 轮 $=2400$s $=40$ 分钟，相比基准 100 分钟压缩 60%。$\square$

## 六、结论

| 问题 | 答案 |
|------|------|
| 朴素 Lagrange 方案是否安全 | **否**：旧成员发送原始份额，接收方可插值主私钥 |
| ECDH 能否修复 | **否**：ECDH 只保护信道，不改变信息量 |
| 正确协议 | 可验证重分享：发 $q_i(j+1)$，证明见 §3 |
| ρ=10% 的安全位数 | **≈52 bit**，低于 128-bit 标准 |
| 理论最优更替率 | $\rho^*=25\%$，精确解下界 $22.85\%$ |
| ρ*=25% 安全位数 | **≈142 bit**，原生超越 128-bit |
| 通信代价 | 报文数节省 40%，差量承诺体积节省 75%，带宽 3.53 Mbps |

工程建议：系统稳态后将 `kChurnRate` 从 10% 迁移至 25%（$k_{\rm new}=256$），满足密码学安全标准，同时保留 TNSE 的核心性能优势。
